Два транспорта, один туннель

Если один способ заблокирован, клиент переключается на другой без вашего участия. Проверки здоровья и защита от флаппинга не дают ему метаться между ними.

Установка в несколько команд

Сервер: Ubuntu VPS с доменом. Клиент — Ubuntu или другой Linux с GUI-окном и треем.

Сервер

Нужен root и домен, указанный на IP VPS.

# сборка
cargo build --release

# установка: nginx, systemd, nftables, decoy-сайт
sudo packaging/server/install.sh --domain vpn.example.com --email admin@example.com

# устройство
sudo rt-ctl add-peer --peers-dir /etc/rtun/peers --name laptop --index 2 \
  --server-config /etc/rtun/server.toml

Клиент

Конфиг создаётся на сервере командой rt-ctl gen-client.

# сборка
cargo build --release

# установка сервиса и polkit-политики
sudo packaging/client/install.sh --config ./client.toml

# окно и трей
rt-client-gui

Приватные ключи не покидают устройство

Ключи пишутся с правами 0600 и не попадают в логи. Сервер хранит только публичные ключи. DNS-запросы и адреса назначения не логируются.

Ключи

Сервер знает только публичные ключи пиров. Приватные, только на клиенте, режим 0600.

Логи

DNS-запросы и адреса назначения не записываются. Логируются состояние и ошибки.

Сайт-приманка

Для ws-tls обязателен декой-сайт. Пакеты с неизвестным заголовком отбрасываются без ответа.

Ответственность

Пользователь сам соблюдает местное законодательство и правила провайдера.
